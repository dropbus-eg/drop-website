سياسة الخصوصية

دي مسودة هيكل للمراجعة، وليست سياسة معتمدة. لازم تأكيد نطاق الموقع والمنصة والتطبيقات وممارسات البيانات قبل النشر النهائي.

1. نطاق السياسة

حدد هل السياسة للموقع العام فقط، أو لمنصة المدارس والتطبيقات أيضًا، وافصل بين كل خدمة بوضوح.

2. المعلومات التي تُجمع

أكد بيانات الاستفسارات والحسابات والطلاب والرحلات والموقع التي تُستخدم فعليًا، ومن يقدر يشوفها.

3. استخدام المعلومات ومشاركتها

وثّق الأغراض الفعلية، والجهات التي تعالج البيانات، والاستضافة، وأي مشاركة مع أطراف أخرى.

4. الاحتفاظ والحقوق

حدد فترات الاحتفاظ والحذف الفعلية وطريقة طلب الوصول أو التصحيح أو الحذف.

5. ملفات الارتباط والتواصل

أكد أي تحليلات أو ملفات ارتباط مستخدمة فعليًا. للاستفسارات: support@dropeg.com.
